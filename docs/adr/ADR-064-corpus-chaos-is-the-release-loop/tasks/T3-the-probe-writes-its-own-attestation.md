# Task ADR-064-T3: The probe writes the attestation from a saved report

**Depends-on:** T1
**Covers:** none — no spec
**Estimated scope:** S (one pure function, one mode)
**Owner:** unassigned
**Produces:** `corpus-probe --attest <label> <report.json>`
**Consumes:** `probe.readers` (T1)
**Data dependency:** hermetic
**Proof map:** v1
**Rests-on:** `release-evidence attests it`, `uncommitted readers leave at null`, `it carries counts only`

## Goal

`corpus-probe --attest <label> <report.json>` runs nothing. It prints the attestation in the `docs/corpus-reports/README.md` schema, field by field:
- `date`: the report's date.
- `at`: `probe.readers.git`, but only when `probe.readers.dirty` is `false`. Otherwise it is `null`, and `atReason` says why: "reader files modified at HEAD", or "the plugin is not a git checkout". `release-evidence` compares commits and cannot see a working tree, so a commit here would attest readers the runner did not run.
- `plugin`: the report's plugin version.
- `kind`: `probe`.
- `probeSha256`: `probe.sha256`.
- `readers`: `probe.readers.sha256`.
- `platform`, `node` and `python`: from the report. T1's report records `python` beside `readers` when it does not already.
- `corpus.records`: `workNext.records`.
- `corpus.tasks`: `workNext.tasks`.
- `corpus.taskDirectories`: the adrNext entries plus `frozenTaskDirs`.
- `couldNotRun`, `disagreements` and `readinessUnproven`: as counts.
- `runner`: the label.
- `found`: the empty string, for the asking session to fill from the diff. The tool never says what a run found.

Every count is `null` when its reader did not answer, never 0. The attestation carries no path, id or string from the corpus.
