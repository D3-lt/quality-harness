## How evidence is graded

- **CONFIRMED** — a command the auditor ran displayed it.
- **PLAUSIBLE** — traced through source, not executed.

A traced finding is never presented as a measured one. That is this project's own rule that a
gate never reports an observation it did not make, applied to the audit itself.

## Checked and kept — do not re-audit

**ADR-060's central invariants hold.** Every one verified rather than assumed:

- **The ledger is computed apart from the rules.** `recordClaim` runs before the `quiet`
  suppression and before every dedupe. **A suppression cannot turn `unverified` into `verified`.**
- A not-ok observation never satisfies a check, and two not-ok observations never compare equal.
- Outside git, a pass clears only unobservable writes recorded before it started; the `startedAt`
  string comparison is sound because `qh-check.mjs:36` emits the format `appendEvent` uses.
- `latestCheckFor`'s record dedupe, seq authority, and "an order we cannot establish must not
  certify" tail are correct as written.
- `alreadyAnswered` correctly refuses `null === null`.
- `importCheckRecords`' `sequence` is stable per record.
- `observe()` does not touch the repository's own index or objects.

**Also cleared, by execution:**

- **`facts-gate-dispatch.sh` terminates** on an unreadable file, a directory, a symlink loop, a
  path with two missing ancestors, and a filename containing both a newline and a double quote.
  All five exit 0 promptly; every miss uses the UNPROVEN vocabulary, never a gate name.
- The **ADR-060 Windows key-escape defect is genuinely fixed**; C1 is a different residue.
- `hooks.json` names no script that does not exist.
- `tests/claims-rate.test.mjs` — no defect found; the strongest test file audited.
- `post-edit-check.sh`'s `| tail -30 || true` is **not** the §16 fail-open: the finding travels in
  the output, not the status, and `set -e` makes `|| true` load-bearing.
