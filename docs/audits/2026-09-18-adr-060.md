- **The ledger is computed apart from the rules.** `recordClaim` runs before the `quiet`
  suppression and before every dedupe. **A suppression cannot turn `unverified` into `verified`.**
- A not-ok observation never satisfies a check, and two not-ok observations never compare equal.

  string comparison is sound because `qh-check.mjs:36` emits the format `appendEvent` uses.

  certify" tail are correct as written.
- `alreadyAnswered` correctly refuses `null === null`.
- `importCheckRecords`' `sequence` is stable per record.
- `observe()` does not touch the repository's own index or objects.

- The **ADR-060 Windows key-escape defect is genuinely fixed**; C1 is a different residue.

- `tests/claims-rate.test.mjs` — no defect found; the strongest test file audited.
